FactoryTwin 3D

Purpose

FactoryTwin 3D is a browser-based educational manufacturing digital twin prototype. It demonstrates how a physical production line can be represented virtually, monitored with simulated sensor readings, and tested with operating scenarios.

Architecture

The application uses React, Vite, TypeScript, Three.js through React Three Fiber, Drei helpers, Tailwind CSS, Recharts, and Lucide icons. Simulation logic is separated from the UI in the FactoryTwin source tree.

Limitations

All sensor readings and point-cloud data are synthetic. The model is not connected to live industrial machinery and the equations are not physically validated.
