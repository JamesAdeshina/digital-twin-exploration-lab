ProductionFlow Simulator

Purpose

ProductionFlow Simulator is an educational discrete-event manufacturing model for queues, finite buffers, station capacity, WIP, throughput, lead time, utilisation, bottlenecks, defects, and machine downtime.

Model

Jobs arrive stochastically, then flow through Cutting, Assembly, and Inspection. FIFO queues sit before each station. If a downstream buffer is full, the upstream machine stays blocked with its completed job until space opens. Rendering explains engine state; it does not determine simulation results.

Scenario lab

Save a baseline, change inputs, run a fixed-duration scenario, and compare seeded replications. Export JSON or CSV summaries for notes and reports.

Limitations

This is not a calibrated factory model. It uses assumed distributions and seeded synthetic data to teach modelling concepts, not to validate real engineering decisions.
