PointCloud Lab

Purpose

PointCloud Lab is an educational 3D computer vision prototype for exploring XYZ point clouds, coordinate frames, geometric transforms, segmentation, downsampling, and imported inspection data.

Controls

Choose cube, cylinder, sphere, machine, or shelf datasets; adjust point count, density, noise, point size, voxel grid, clipping, and plane separation; then translate, rotate, or scale the processed cloud while the live 4x4 transform matrix and comparison metrics update.

Data exchange

Import simple XYZ/CSV text files with columns such as x, y, z, intensity. Export the processed point cloud as CSV or capture the current scene as a PNG for notes and reports.

Limitations

Procedural points and imported files are displayed for learning only. The app is not a validated metrology, LiDAR, CT, or industrial inspection system.
